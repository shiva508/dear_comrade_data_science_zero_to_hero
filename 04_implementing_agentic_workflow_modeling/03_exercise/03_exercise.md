# Exercise: Transform a Deterministic Flow into an Agentic Workflow
### Here’s a challenge for you: Imagine you're redesigning an Emergency Aid Dispatch system. In the old system, when a request comes in, one central process checks inventory, then checks the weather, then checks road conditions, all one after the other – a bit like a single, overworked manager
### What if we could unleash a team of specialist 'agents' to tackle these critical checks – inventory, weather, roads – all at the same time? How would that change the picture? And if these agents are working in parallel, how does our central 'manager' (let's call it a Strategic Agent) make sense of all that information potentially flooding back at once to make the critical dispatch decision?
### Your mission in this exercise is to become a workflow architect. You'll take an incomplete, somewhat linear flowchart representing the old way and transform it into a new, agentic model using the Mermaid.js diagramming syntax you can run at mermaid.live(opens in a new tab) (recommended) or a local editor/IDE with a Mermaid preview extension (like in VS Code).
- No programming language is required for this exercise, just your logical thinking and a bit of Mermaid syntax!
